# ETF 엑스레이 데이터

앱이 읽는 데이터 파일을 자동으로 만들고 공개하는 저장소예요.

## 만들어지는 파일 (공개 주소: `https://inchbyinch247.github.io/etf-xray-data/v1/...`)

| 파일 | 내용 |
|---|---|
| `v1/holdings/<티커>.json` | ETF 1개의 구성종목과 비중(%), 기준일 |
| `v1/instruments.json` | 검색용 종목 목록 (ETF + 주식) |
| `v1/meta.json` | 만든 시각, 출처 |

검토용 파일 `reports/us_etf_list.csv`(미국), `reports/kr_etf_list.csv`(국내)에는 선정된 ETF와 빠진 ETF, 빠진 이유가 적혀 있어요. 엑셀로 열 수 있어요.

## 손으로 바꿀 수 있는 것: `config/us_etfs.json`, `config/kr_etfs.json`

- `exclude`: 빼고 싶은 ETF 티커. 예: `["ARKK"]`
- `include`: 순위나 주식 비중과 상관없이 꼭 넣을 티커
- `names`: 앱에 보일 이름 바꾸기

## 필요한 설정 (Settings → Secrets and variables → Actions)

- Variables `SEC_USER_AGENT`: `이름 실제이메일` — SEC는 연락 가능한 이메일이 없으면 거부해요.
- Secrets `KRX_ID`, `KRX_PW`: 한국거래소 정보데이터시스템(data.krx.co.kr) 아이디·비밀번호. 2026년 2월부터 로그인해야 데이터를 받을 수 있어요. 소셜 로그인으로 가입했다면 '내 정보 수정'에서 아이디·비밀번호 로그인을 켜야 해요.
- Secrets `OPENFIGI_API_KEY` (선택): 미국 종목 티커 변환을 빠르게 해요.

## 선정 기준 — 국내

1. 한국거래소 정보데이터시스템의 ETF 전종목 자료에서 순자산 1,000억 원 이상인 ETF를 고른다.
2. 자산 분류가 '주식'이 아닌 ETF(채권·원자재·통화 등)는 뺀다.
3. 이름에 레버리지·인버스·2X·선물·합성이 들어간 ETF도 뺀다.
4. 구성종목(PDF)에서 주식 비중이 60% 미만인 ETF(스왑·현금 위주)도 뺀다.

## 선정 기준 — 미국

1. SEC에 공시된 펀드 중 ETF(티커 4글자 이하)만 고른다.
2. 순자산 큰 순으로 정렬한다.
3. 주식(보통주·우선주) 비중이 60% 미만인 펀드(채권·원자재·현금형)는 뺀다.
4. 이름에 레버리지·인버스 표시(2X, 3X, Ultra, Inverse, Bear, Bull, Daily 등)가 있는 펀드도 뺀다.
5. 위에서부터 300개를 고른다.

## 알아 둘 점

- SEC 공시는 분기 말 기준 자료가 약 60일 뒤에 공개돼서, 기준일이 몇 달 전이에요. 파일마다 `asOf`에 기준일이 적혀 있어요.
- 뱅가드 ETF는 같은 펀드의 뮤추얼펀드 자금까지 합친 순자산으로 순위가 매겨져요.
- 종목 키 규칙:
  - 미국 상장 종목: 티커 (`BRK.B` 형식)
  - 국내 종목: 6자리 코드 (`005930`)
  - 그 밖의 해외 종목: ISIN
- 비중 0.001% 미만인 종목은 파일에서 생략돼요. 생략된 비중은 앱에서 '기타'로 보여요.
